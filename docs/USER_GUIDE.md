# SafeChat AI SOC – User Guide

## Introduction

SafeChat AI SOC is an AI-powered Security Operations Center that helps organizations detect, investigate, and respond to cyber threats in real time.

---

# Logging In

Open:

```
http://localhost:3000
```

Log in using your assigned account credentials.

Available roles include:

* Administrator
* Executive
* Security Analyst
* Customer
* Viewer

---

# Customer Dashboard

The Customer Dashboard allows users to:

* Submit messages for security analysis
* View scan history
* Monitor detected threats
* Review AI recommendations

---

# SOC Dashboard

The SOC Dashboard provides:

* Live attack graph
* Threat timeline
* Incident management
* Threat hunting
* Security analytics
* AI SOC Analyst
* MITRE ATT&CK mapping

---

# Executive Dashboard

Executives can monitor:

* Enterprise security posture
* Risk score
* Threat pressure
* Executive AI recommendations
* Business impact
* Security KPIs

---

# Threat Hunting

Use the Threat Hunting Workspace to search for:

* Malware
* Phishing
* Ransomware
* Indicators of Compromise (IOCs)
* Threat categories

---

# Incident Management

Security analysts can:

* Investigate incidents
* Assign incidents
* Resolve incidents
* Review evidence
* Track incident status

---

# Reports

The platform supports exporting reports in:

* PDF
* CSV

---

# Best Practices

* Investigate high-risk incidents first.
* Keep user credentials secure.
* Review AI recommendations before taking action.
* Export reports regularly for auditing.
* Monitor the attack graph for unusual activity.

---

# Support

If you encounter issues during beta testing, document:

* Steps to reproduce
* Expected result
* Actual result
* Screenshots (if applicable)

Provide this information to the project administrator.
